# APP-V2 Phase 0 / S0 Handoff Package

This package is the **single-sprint developer handoff** for `app-v2-alpha`.

Start with `CLAUDE_S0_PROMPT.md`.

The package deliberately avoids choosing a framework, ORM, or database because S0 must preserve the repository's existing stack.

## Package content

- `CLAUDE_S0_PROMPT.md`
- `IMPLEMENTATION_CONTRACT.md`
- `SOURCE_AUTHORITY.md`
- `S0_ACCEPTANCE_GATE.md`
- `seed_data.json`
- `seed_data.schema.json`
- `repo_tree.txt`
- `phase0_manifest.json`

## Stop rule

Once S0 passes its acceptance gate, stop development and review GitHub before S1.
