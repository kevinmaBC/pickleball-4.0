# S6 Scope

## MAY
- explain PASS/FAIL/BORDERLINE/LOW_CONFIDENCE/INCOMPLETE;
- explain capability components, weights, threshold and margin;
- explain each hard gate with observed/required/direction/status/margin;
- explain evidence minimum from explicit C-level input;
- explain match validation;
- explain missing inputs;
- explain provisional 4.5/5.0;
- emit stable machine reason codes + concise human text;
- emit provenance/evidence trace.

## MUST NOT
- reclassify or override S5;
- derive evidence confidence;
- derive assessment metrics from S2/S3;
- rank bottlenecks or weakest skill;
- recommend drills/blocks;
- prescribe training;
- build P0–P6;
- promote player;
- interpret DUPR;
- persist anything;
- redesign UI;
- do S7.

A failed gate is a classification blocker, not automatically a bottleneck.
